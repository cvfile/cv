# .impeccable.md

Design context for cvfile.org, the website of the `.cv` open resume file format.

## Design Context

### Users
Three audiences, served by one website that leads format-first.
1. **Developers and AI / RAG builders** (primary voice): integrate the SDKs, read the embedded Markdown and precomputed vectors, want technical credibility and copy-pasteable code.
2. **Job seekers**: create one `.cv` in the browser, upload it everywhere, never juggle four drifting artifacts.
3. **ATS, CRM and recruitment platforms**: ingest `.cv` through the server middleware and content negotiation; the wrapper stays invisible to their crawlers.

### Brand Personality
Precise, engineered, archival, open. The voice of a standards body that happens to have a design team. Confident, plain, no hype. The product is infrastructure, so the site reads like a well-drawn technical document, not a SaaS landing page.

### Aesthetic Direction
**Engineered blueprint, rendered as a warm engineering vellum drawing.** The site is a technical drawing of the file format. The deliberate subversion: a classic blueprint is cyan-on-dark (the banned "AI palette"), so we use bone/vellum paper, graphite ink, and a single draftsman's **vermilion** accent. The "engineered" feeling comes from a hairline grid, dimension-line annotations, a left margin rail with §-numbers, and a schematic of the container, never from blue or glow.

- **Theme**: light primary + a genuine dark variant via `light-dark()` and `prefers-color-scheme`. Light is warm vellum; dark is warm ink (not blue-black).
- **Type**: Archivo (display), Hanken Grotesk (body), Spline Sans Mono (labels, code, annotations). No Inter / IBM Plex / Space Grotesk / DM family.
- **Signature element**: the exploded `.cv` schematic on the homepage (container frame, four payload rows, primary payload marked vermilion, corner ticks, dimension labels).
- **Anti-references**: generic indigo/cyan SaaS landing pages, gradient text, glass cards, evenly padded card grids, hero metric templates.

### Design Principles
1. **The drawing is the brand.** Hairline rules, mono dimension labels, §-numbered margin rails, and the file schematic carry the identity. Decoration must read as annotation.
2. **Vermilion is rare.** One accent, ~10% weight, reserved for the primary payload, active nav, CTAs, and section markers. Never a glow, never a gradient.
3. **Tint everything warm.** Surfaces, ink and lines are all tinted toward the warm vellum hue (OKLCH ~70 to 86). No pure black or white.
4. **Left-aligned and asymmetric.** Content sits to the right of an annotation rail; dropzones are the only centered elements.
5. **Tokens, not inline styles.** All color, type and spacing come from the CSS custom properties and component classes in `docs/src/layouts/Page.astro`. New pages wrap content in `.sheet` (marketing) or `.doc` (document pages).

Implementation lives in `docs/` (Astro static site). Shared system and chrome: `docs/src/layouts/Page.astro`.
